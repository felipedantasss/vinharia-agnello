# 🍷 Vinharia Agnello

## Sobre o projeto

A Vinharia Agnello é um projeto desenvolvido para apresentar uma experiência relacionada ao universo dos vinhos.

O site apresenta a história da Vinharia, diferentes tipos de vinhos, experiências de degustação e uma área de contato para solicitação de visitas.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Páginas do projeto

- Início
- História
- Vinhos
- Experiências
- Contato

## Funcionalidades

- Menu de navegação entre as páginas
- Imagens
- Vídeo
- Lista de experiências
- Tabela de vinhos
- Formulário de contato
- Layout responsivo
- Links entre as páginas

## Objetivo

O objetivo do projeto é aplicar conhecimentos de desenvolvimento web utilizando HTML5 e CSS3, trabalhando estrutura semântica, navegação, formulários, tabelas, imagens, vídeos e estilização.
